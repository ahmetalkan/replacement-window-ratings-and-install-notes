# Replacement Window Ratings and Installation Notes

A homeowner reference for reading NFRC energy labels (U-factor, SHGC, visible transmittance), comparing vinyl, fiberglass, and wood-clad frames, and distinguishing pocket-insert from full-frame installation, citing ENERGY STAR and NFRC.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — replacement window performance and installation overview: `https://ahmetalkan.github.io/replacement-window-ratings-and-install-notes/`
- Subpage — reading U-factor, SHGC, visible transmittance, and air leakage: `https://ahmetalkan.github.io/replacement-window-ratings-and-install-notes/u-factor-shgc-and-nfrc-labels.html`
- Subpage — comparing vinyl, fiberglass, composite, and wood-clad window frames: `https://ahmetalkan.github.io/replacement-window-ratings-and-install-notes/vinyl-fiberglass-and-wood-frames.html`
- Subpage — pocket insert replacement vs full-frame tear-out installation: `https://ahmetalkan.github.io/replacement-window-ratings-and-install-notes/insert-vs-full-frame-install.html`

It cites public pages on [windowreplacementlab.com](https://windowreplacementlab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
